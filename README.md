# The Rift (Разлом)

> **2.5D Top-Down Sci-Fi Roguelike Co-op**, вдохновленный **Risk of Rain 2**.  
> Одиночная игра и кооператив до 5 игроков по сети (WebRTC / Dedicated Server).

---

## 🌌 О Проекте

**«The Rift»** — это динамичный научно-фантастический roguelike с изометрической камерой и умной автострельбой. Игроки берут на себя роль исследователей, чей корабль потерпел крушение на неизведанной планете **Этельгард (Nexus-IV)**. Мир пронизан пространственными разломами, порождающими бесконечные орды мутантов и древних охранных механизмов.

### Ключевые Особенности:
- ⏳ **Враг — это Время:** Динамическая шкала сложности постоянно растет, усиливая монстров и элиту с опасными аффиксами.
- 🎒 **Бесконечный Стек Предметов и Прок-Цепочки:** Предметы разных тиров редкости (Common, Uncommon, Legendary, Boss, Corrupted) взаимодействуют между собой, превращая персонажа в ходячую армию.
- 🌀 **События Телепорта и Битвы с Боссами:** На каждой локации нужно найти древний Телепорт, активировать его, сдержать натиск монстров и сокрушить стража локации ради перехода на следующий биом.
- 🎯 **Умная Автострельба:** Игрок сосредотачивается на тактическом позиционировании, уклонениях, кайтинге и активации способностей, а оружие самостоятельно захватывает приоритетные цели.
- 🤝 **Кооператив до 5 Игроков:** P2P WebRTC соединение без выделенных серверов или выделенный Node.js/Bun headless сервер. Система нокдаунов и возрождения союзников.

## 🗺️ Биомы Планеты Этельгард
1. **Пепельные Пустыни (The Ashen Wastes):** Барханы, остовы челноков, песчаные черви и големы.
2. **Комплекс «Омега» (Derelict Sector 7):** Заброшенные лаборатории, лазерные ловушки, боевые автоматоны.
3. **Ксено-Джунгли (Bioluminescent Wilds):** Биолюминесцентные грибы, токсичные споры, роящиеся ксеноморфы.
4. **Базальтовая Кальдера (Volcanic Forge):** Лавовые реки, плазменные разломы, огненные элементали.
5. **Руины Предтеч (Primordial Monoliths):** Парящие монолиты, кинетические призмы, стражи разлома.
6. **Ядро Разлома (The Rift Core):** Финальная эвакуация и битва с Архитектором Разлома.

Полный дизайн-документ игры с таблицами предметов, классами и формулами доступен в [`docs/GAME_DESIGN.md`](./docs/GAME_DESIGN.md).

## 🛠️ Архитектура

Проект построен по принципу **Headless Authoritative Simulation**:
- **`src/sim/` (GameCore):** 100% чистая логика (игроки, физика, враги, оружие, статы, снапшоты) без зависимостей от Three.js/DOM.
- **`src/core/` & `src/entities/`:** Презентационный слой Three.js (2.5D рендер, шейдеры, эффекты, звук).
- **`src/net/` & `server/`:** Сетевой транспорт WebRTC (PeerJS) и выделенный Node.js сервер.

Подробнее об архитектуре: [`docs/SERVER_ARCHITECTURE.md`](./docs/SERVER_ARCHITECTURE.md).

## 🚀 Быстрый Старт

### Требования
- [Node.js](https://nodejs.org/) v20+ или v22+
- npm

### Установка зависимостей
```powershell
npm install
```

### Запуск клиента разработки
```powershell
npm run dev
```

### Проверка типов и сборка
```powershell
npm run typecheck
npm run build
```

### Запуск выделенного сервера (опционально)
```powershell
npm run server
```

## 📜 Управление
| Клавиша | Действие |
| :--- | :--- |
| **W, A, S, D** | Перемещение персонажа |
| **Автоматически** | Автострельба по приоритетным целям |
| **Пробел / Shift** | Тактический рывок / Уклонение |
| **Q** | Классовая способность (Граната, Щит, Турель, Сингулярность) |
| **R** | Активируемый артефакт (Equipment) |
| **E / F** | Взаимодействие (Сундуки, Принтеры, Телепорт) |
