# Optional UI portrait — not an animation sheet

Attach the original reference, the approved turnaround, and reference `references/chibi_style_reference.png`. Create one 128×128 pixel-art portrait/avatar of the **same approved character** for UI use. Preserve face, skin tone, eyes, headgear, hair, costume palette, and serious battle-ready expression. The crop should remain readable at small UI size.

## Mandatory Negative Constraints
No anime style, no kawaii style, no cute expression, no childish appearance, no soft pastel colors, no realistic proportions, no photorealism, no smooth gradients.

## Art Style & Facial Guidelines
- **Mature face**: Sharp angular jaw, fierce/determined battle glare, small-to-medium sharp eyes with dark outline. Scars, stubble, or beards where appropriate.
- **Strictly forbidden**: No anime eyes, no kawaii blush, no cute baby face, no childish expression, no soft pastel colors, no smooth gradients.
- **Rendering**: Clean 16-bit-style pixel art, crisp hard edges, deliberate pixel clusters, consistent dark outlines, saturated dark fantasy palette. Pure solid white background RGB(255,255,255). No border, text, UI frame, scenery, effects, or redesign.

This file is optional and must not be included in the three animation sheets.
