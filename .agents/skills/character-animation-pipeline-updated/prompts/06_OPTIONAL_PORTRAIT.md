# Optional UI Portrait — Single 96×96 Avatar Frame

Create one 96×96 pixel-art portrait/avatar of the **same approved character** for UI dialogs and HUD frames. Preserve face, skin tone, eyes, headgear, hair, costume palette, and serious battle-ready expression. The crop should remain readable at small UI size.

---

## 1. Mandatory Negative Constraints
> `No anime style, no kawaii style, no cute expression, no childish appearance, no soft pastel colors, no realistic proportions, no photorealism, no smooth gradients.`

---

## 2. Art Style & Facial Guidelines
* **Mature Face**: Sharp angular jaw, fierce/determined battle glare, small-to-medium sharp eyes with dark outline. Scars, stubble, or beards where appropriate.
* **Strictly Forbidden**: No anime eyes, no kawaii blush, no cute baby face, no childish expression, no soft pastel colors, no smooth gradients.
* **Rendering**: Clean 16-bit-style pixel art, crisp hard edges, deliberate pixel clusters, consistent dark outlines, saturated dark fantasy palette.
* **Background**: Pure solid flat white background `rgb(255,255,255)` (`#ffffff`). No border, text, UI frame, scenery, drop shadows, or redesign.

*Note: This file is optional and must not be packed into the three animation sheets.*
