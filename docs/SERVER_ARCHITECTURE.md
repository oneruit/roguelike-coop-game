# Архитектура Сервера и Игрового Ядра (GameCore)

Данный документ описывает модульную архитектуру **GameCore**, спроектированную по принципу **Headless Authoritative Simulation** (детерминированная симуляция без графических зависимостей).

---

## 1. Концепция: Разделение Симуляции (GameCore) и Отображения (Renderer)

Раньше игровые сущности (`Enemy`, `Projectile`, `Gem`, `Player`) создавали `THREE.Group`, `THREE.Mesh`, материалы и обращались к DOM прямо внутри своей логики. Из-за этого запуск логики на выделенном сервере (Linux VPS / Node.js / Bun) требовал бы полной переработки кода или тяжелых эмуляций WebGL/Canvas.

Теперь игровая архитектура разделена на два изолированных слоя:

```
┌────────────────────────────────────────────────────────┐
│              Headless GameCore (src/sim/)              │
│  - Математика: SimVec3, SimRNG (детерминированный PRNG)│
│  - Игроки: SimPlayer (ХП, баффы, XP, статы, оружие)    │
│  - Враги: SimEnemy, волны, AI преследования цели       │
│  - Оружие и Пули: SimWeapon, траектории, пробивание    │
│  - Коллизии: Круговые/сферические пересечения (урон)   │
│  - Дропы и Алтари: Опыт, магниты, командные баффы      │
│  - События: SimEvent (урон, смерть, звук, апгрейд)     │
│  - Снапшоты: getSnapshot() для синхронизации по сети   │
│  * 0% зависимостей от THREE.js, window, document       │
└────────────────────────────────────────────────────────┘
                           ▲
                           │ Ввод (Input) / Снапшоты (Snapshots)
                           ▼
┌────────────────────────────────────────────────────────┐
│             Presentation Layer (Клиент / Three.js)     │
│  - Three.js Scene, 3D меши, 2.5D спрайты, тени         │
│  - SoundManager (Web Audio API)                        │
│  - DamageNumberManager (HTML/3D всплывающий урон)      │
│  - HUD & Меню (DOM элементы)                           │
│  - InputManager (клавиатура, мышь, геймпад)            │
└────────────────────────────────────────────────────────┘
```

---

## 2. Текущий режим: Host-Based (Клиентский Хост)

В текущей версии игра работает без необходимости оплачивать сторонние серверы:
- **Соло-режим**: `GameCore` запускается локально в браузере игрока.
- **Кооператив (до 5 игроков)**: Хост запускает `GameCore`. Клиенты подключаются по WebRTC (PeerJS) и отправляют хосту только команды перемещения (`CLIENT_INPUT` / `CLIENT_SYNC`). Хост скармливает их в `GameCore.setPlayerInput(id, input)`, выполняет `GameCore.tick(dt)` и рассылает снапшот `GameCore.getSnapshot()` всем участникам.

## 3. Переход на Dedicated Server (Node.js / Bun / VPS)

Когда вы решите развернуть выделенный сервер (например, арендовать VDS на Linux или облачный инстанс):

### Не нужно переписывать механику!
Логика мобов, пуль, формулы урона, спавн волн, XP, уровни и алтари уже вынесены в `src/sim/GameCore.ts` и `src/sim/SimWeapons.ts`. Они выполняются в Node.js/Bun «из коробки».

### Готовый раннер сервера: `server/dedicatedServer.ts`
В проекте уже подготовлен готовый серверный файл `server/dedicatedServer.ts`.

Для запуска на сервере:
```bash
# Запуск через Bun:
bun server/dedicatedServer.ts

# Либо через Node.js / ts-node:
npx ts-node server/dedicatedServer.ts
```

### Как устроен серверный цикл (30 Hz):
```typescript
import { GameCore } from '../src/sim/GameCore';

const serverCore = new GameCore({ seed: 42, isCoop: true, tickRate: 30 });
const dt = 1 / 30;

// Серверный фиксированный тик (33.3 мс)
setInterval(() => {
  // 1. Симуляция мира
  const events = serverCore.tick(dt);

  // 2. Получение авторитетного снапшота
  const snapshot = serverCore.getSnapshot();

  // 3. Рассылка по WebSocket / WebRTC всем подключенным игрокам
  broadcastToAllPlayers({ type: 'SNAPSHOT', snapshot, events });
}, 1000 / 30);
```

### Преимущества такой архитектуры:
1. **Абсолютная защита от читов**: расчет урона, спавн опыта, жизни боссов и хитбоксы пуль происходят на сервере, клиент не может подделать убийства монстров.
2. **Детерминизм**: PRNG `SimRNG` позволяет одинаково воспроизводить симуляцию или сохранять матчи в реплеи.
3. **Плавная миграция**: можно в любой момент переключить один флаг (`mode: 'local_host' | 'dedicated_client'`) в `GameCoreBridge.ts`.
